Лабораторна робота №7 — Функції
Завдання:

 -Розробити програму, яка:

1. використовує функції для виконання основних обчислень;

2. приймає ціле число і перевіряє, чи є воно простим;

3. демонструє роботу функцій з різними вхідними даними;

4. у випадку відсутності аргументів командного рядка використовує значення за замовчуванням;

 -додатково реалізує:

 5. створення та виведення випадкової квадратної матриці;

 6. обчислення квадрату матриці (A²);

 7. знаходження детермінанта матриці (до 3×3 включно);

 8. забезпечує використання генератора псевдовипадкових чисел (rand()).
