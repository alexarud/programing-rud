1. Завдання

Індивідуальні завдання

Переробити програми, що були розроблені під час виконання лабораторних робіт з тем
“Масиви” та “Цикли” таким чином, щоб використовувалися функції для обчислення результату.

Функції повинні задовольняти головну мету — уникати дублювання коду.
Для демонстрації роботи програма (функція main()) повинна мати можливість викликати розроблені функції з різними вхідними даними.

Слід звернути увагу:

параметри одного з викликів функцій повинні бути згенеровані за допомогою генератора псевдовипадкових чисел rand();

інший виклик повинен приймати вхідні дані через аргументи командного рядка;

якщо аргументи не передано — дані беруться за замовчуванням, обрані розробником.

Додаткові завдання складного рівня

використовуючи варіативну функцію (функцію зі змінною кількістю аргументів).

Приклад:
Для вхідних даних {3, 2, 4, 3, 1} результат = 3 (пари (3,2), (2,4), (3,1)).

2. Реалізувати функцію, що знаходить детермінант квадратної матриці (до 3×3 включно).
Прототип функції:
int get_determinant(int[] matrix, size_t rows, size_t cols);

3. Хід виконання завдання
3.1. Створення проєкту та вихідного коду

Було створено структуру проєкту lab07/ відповідно до вимог.
У каталозі src/ створено файл main.c, у якому реалізовано такі функції:

 bool isPrime(int number) — перевірка, чи є число простим;

 int random_int(int min, int max) — генерація випадкового числа;

 void printMatrix(int matrix_array[], int rows, int cols) — виведення матриці;

 void squareMatrix(int matrix_array[], int rows, int cols, int result[]) — множення матриці самої на себе;

 int countIncreasingPairs(int count, ...) — підрахунок зростаючих пар (варіативна функція);

 int get_determinant(int matrix[], int rows, int cols) — знаходження детермінанта квадратної матриці (до 3×3);

 int main() — головна функція, що демонструє роботу усіх попередніх.

3.2. Визначення точки входу

Головна функція int main() розташована у файлі main.c.
У ній:

отримується число через аргументи командного рядка (argv);

генерується випадкова матриця 3×3;

викликаються функції для перевірки простоти числа, підрахунку пар, обчислення детермінанта, множення матриці тощо.

3.3. Реалізація функцій

 1. Функція перевірки простоти (isPrime)
Реалізована через цикл for. Перевіряє, чи має число дільники у діапазоні [2, n-1].

 2. Функція countIncreasingPairs
Використовує механізм va_list, що дозволяє передавати довільну кількість аргументів.
Підраховує всі пари елементів, у яких перше менше за друге.

 3. Функція get_determinant
Використовує формули:

для 2×2: ad - bc

для 3×3: правило Саррюса.

 4. Функція squareMatrix
Виконує множення матриці самої на себе, використовуючи потрійний цикл.

 5. Функція random_int
Повертає псевдовипадкове ціле число в межах [min, max].
