## 2. ОПИС ПРОГРАМИ

### 2.1. Функціональне призначення

Програма призначена для роботи з динамічними двовимірними масивами (матрицями).
Основні можливості:
1. Генерація квадратної матриці розміром `N x N` з випадковими числами.
2. Виділення елементів головної діагоналі в окремий динамічний масив.
3. Сортування отриманого масиву діагоналі за зростанням.
4. Виведення початкової матриці та відсортованої діагоналі.
5. Коректне звільнення пам'яті.

### 2.2. Опис логічної структури

#### 2.2.1. Структура функцій

Основні функції програми (описи відповідають коментарям Doxygen):

- `void copy_main_diagonal(int **matrix, int n, int *diag)`
  Копіює елементи головної діагоналі матриці `matrix` розміром `n x n` у масив `diag`. Використовує адресну арифметику.

- `void sort_array(int *arr, int n)`
  Сортує масив `arr` довжиною `n` за зростанням методом обміну (Bubble Sort або аналогічний).

- `void print_matrix(int **matrix, int n)`
  Виводить квадратну матрицю `n x n` у консоль.

- `void print_array(int *arr, int n)`
  Виводить елементи одновимірного масиву у консоль.

- `int main(void)`
  Точка входу. Виконує виділення пам'яті, ініціалізацію даних, виклик функцій обробки та звільнення пам'яті.

### 2.3. Опис та реалізація функцій

#### 2.3.1. Функція copy_main_diagonal

**Призначення:** Копіює головну діагональ матриці в масив.

**Код:**
```c
void copy_main_diagonal(int **matrix, int n, int *diag) {
    for (int i = 0; i < n; i++) {
        *(diag + i) = *(*(matrix + i) + i);
    }
}
```

#### 2.3.2. Функція sort_array

**Призначення:** Сортує масив за зростанням.

**Код:**
```c
void sort_array(int *arr, int n) {
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (*(arr + j) < *(arr + i)) {
                int temp = *(arr + i);
                *(arr + i) = *(arr + j);
                *(arr + j) = temp;
            }
        }
    }
}
```

#### 2.3.3. Функція print_matrix

**Призначення:** Виводить матрицю на екран.

**Код:**
```c
void print_matrix(int **matrix, int n) {
    for (int i = 0; i < n; i++) {
        int* row = *(matrix + i);
        for (int j = 0; j < n; j++) {
            printf("%d\t", *(row + j));
        }
        printf("\n");
    }
}
```
