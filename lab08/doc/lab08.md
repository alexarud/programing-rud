## 2. ОПИС ПРОГРАМИ

### 2.1. Функціональне призначення

Програма демонструє використання:

- звичайних функцій (перевірка простоти числа, робота з матрицями);
- варіативної функції (робота з довільною кількістю параметрів);
- обчислення детермінанта квадратної матриці до розміру 3×3.

Основні можливості програми:

1. Зчитати число з аргументів командного рядка (або використати значення за замовчуванням).
2. Перевірити, чи є це число простим.
3. Продемонструвати роботу варіативної функції, що рахує кількість зростаючих пар.
4. Згенерувати випадкову квадратну матрицю 3×3.
5. Обчислити квадрат матриці (A²).
6. Обчислити детермінант вихідної матриці.
7. Вивести результати у консоль.

**Обмеження на застосування:**

- детермінант коректно обчислюється лише для квадратних матриць розміром до 3×3;
- вхідні параметри командного рядка мають бути цілими числами;
- максимальна кількість аргументів для варіативної функції обмежена розміром внутрішнього масиву (1000 елементів).

### 2.2. Опис логічної структури

#### 2.2.1. Структура функцій

Основні функції програми (описи відповідають коментарям Doxygen):

- `bool isPrime(int number)`  
  Перевіряє, чи є ціле число простим. Повертає `true`, якщо число просте, і `false` в інших випадках.

- `int random_int(int minimum, int maximum)`  
  Генерує випадкове ціле число в діапазоні `[minimum, maximum]`. Використовує стандартну функцію `rand()`.

- `void printMatrix(int matrix_array[], int rows, int cols)`  
  Виводить матрицю, що зберігається в одновимірному масиві, у вигляді таблиці `rows × cols`.

- `void squareMatrix(int matrix_array[], int rows, int cols, int result[])`  
  Обчислює квадрат квадратної матриці `A²` і зберігає результат у масиві `result`.

- `int countIncreasingPairs(int count, ...)`  
  Варіативна функція, яка рахує кількість пар `(i, k)` таких, що `i < k` і `array[i] < array[k]`.

- `int get_determinant(int matrix[], int rows, int cols)`  
  Обчислює детермінант квадратної матриці розміром до 3×3, заданої одновимірним масивом.

- `int main(int argc, char* argv[])`  
  Точка входу. Керує викликами всіх перелічених функцій, організовує демонстрацію їх роботи.

### 2.3. Опис та реалізація функцій

#### 2.3.1. Функція isPrime

**Призначення:** Перевіряє, чи є ціле число простим.

**Код:**
```c
bool isPrime (int number){
   if (number <= 1) {
      return false; // числа <=1 не є простими
   }
   for (int i = 2; i < number; i++) {
      if (number % i == 0) {
         return false; // якщо знайдено дільник - число не просте
      }
   }
   return true; // якщо не знайдено дільників - число просте
}
```

**Варіант використання:**
```c
bool result = isPrime(17);
if (result) {
    printf("17 is prime");
}
```

#### 2.3.2. Функція random_int

**Призначення:** Генерує випадкове ціле число у заданому діапазоні.

**Код:**
```c
int random_int(int minimum, int maximum){
   return (rand() % (maximum - minimum + 1)) + minimum;
}
```

**Варіант використання:**
```c
srand(time(NULL)); // Ініціалізація генератора
int random_val = random_int(1, 100);
printf("Random value: %d", random_val);
```

#### 2.3.3. Функція printMatrix

**Призначення:** Виводить матрицю, що зберігається в одновимірному масиві, у вигляді таблиці.

**Код:**
```c
void printMatrix (int matrix_array[], int rows, int cols){
   for (int i = 0; i < rows; i++) {
      for (int j = 0; j < cols; j++) {
         printf("%d\t", matrix_array[i * cols + j]);
      }
      printf("\n");
   }
}
```

**Варіант використання:**
```c
int matrix[4] = {1, 2, 3, 4};
printMatrix(matrix, 2, 2);
/* Вивід:
   1    2
   3    4
*/
```

#### 2.3.4. Функція squareMatrix

**Призначення:** Обчислює квадрат матриці (множить матрицю саму на себе).

**Код:**
```c
void squareMatrix (int matrix_array[], int rows, int cols, int result[]){
   for (int i = 0; i < rows; i++) {
      for (int j = 0; j < cols; j++) {
         result[i * cols + j] = 0;
         for (int k = 0; k < cols; k++) {
            result[i * cols + j] += matrix_array[i * cols + k] * matrix_array[k * cols + j];
         }
      }
   }
}
```

**Варіант використання:**
```c
int A[4] = {1, 2, 3, 4};
int B[4]; // Масив для результату
squareMatrix(A, 2, 2, B);
```

#### 2.3.5. Функція countIncreasingPairs

**Призначення:** Варіативна функція, що рахує кількість пар елементів `(i, k)`, де `i < k` і `array[i] < array[k]`.

**Код:**
```c
int countIncreasingPairs(int count, ...){
   va_list args;
   va_start(args, count);
   int pairs_count = 0;
   int array_count[1000];

   for(int i = 0; i < count; i++){
      array_count[i] = va_arg(args, int);
   }

   for(int i = 0; i < count; i++){
      for(int k = i + 1; k < count; k++){
         if(array_count[i] < array_count[k]){
            pairs_count++;
         }
      }
   }
   va_end(args);
   return pairs_count;
}
```

**Варіант використання :**
```c
// Передаємо 5 чисел: 1, 2, 3, 4, 5
int pairs = countIncreasingPairs(5, 1, 2, 3, 4, 5);
printf("Pairs: %d", pairs); // Очікується 10 пар
```

#### 2.3.6. Функція get_determinant

**Призначення:** Обчислює детермінант квадратної матриці (розміром до 3x3).

**Код:**
```c
int get_determinant(int matrix[], int rows, int cols){
   if (rows != cols) return 0;
   if (rows == 1) return matrix[0];
   if (rows == 2) return matrix[0] * matrix[3] - matrix[1] * matrix[2];
   if (rows == 3) {
      int a = matrix[0], b = matrix[1], c = matrix[2];
      int d = matrix[3], e = matrix[4], f = matrix[5];
      int g = matrix[6], h = matrix[7], i = matrix[8];
      return a * (e * i - f * h) - b * (d * i - f * g) + c * (d * h - e * g);
   }
   return 0;
}
```

**Варіант використання:**
```c
int M[9] = {1, 0, 0, 0, 1, 0, 0, 0, 1}; // Одинична матриця 3x3
int det = get_determinant(M, 3, 3);
printf("Determinant: %d", det); // Очікується 1
```
