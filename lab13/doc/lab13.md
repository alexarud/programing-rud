## 2. ОПИС ПРОГРАМИ

### 2.1. Функціональне призначення

Програма призначена для виведення ієрархічної структури файлів та каталогів у вигляді дерева.

Основні можливості:
1. Прийняти шлях до кореневого каталогу як аргумент командного рядка.
2. Рекурсивно обійти всі вкладені каталоги та файли.
3. Вивести структуру у вигляді дерева (з символами `|--`, `` `-- ``, `|   `) одночасно в консоль та у вихідний файл.
4. Вивести підсумок: кількість каталогів та файлів.

**Обмеження на застосування:**

- виклик функції `system()` заборонено;
- програма не очікує жодного вводу від користувача під час роботи;
- вихідний файл не потрапляє до системи контролю версій.

### 2.2. Опис логічної структури

#### 2.2.1. Структура функцій

- `void write_to_file(FILE *f, const char *data)`
  Записує рядок `data` у відкритий файл за допомогою `fprintf`.

- `void print_tree(const char *path, const char *prefix, FILE *out, int *dirs, int *files)`
  Рекурсивно обходить каталог `path`. Відкриває його через `opendir`, збирає імена записів у динамічний масив, сортує їх алфавітно через `qsort`, потім для кожного запису виводить рядок з відповідним префіксом (`|-- ` або `` `-- ``). Для каталогів рекурсивно викликає себе з новим префіксом. Рахує каталоги та файли через покажчики `dirs` і `files`.

- `int main(int argc, char *argv[])`
  Точка входу. Приймає два аргументи: шлях до каталогу та шлях до вихідного файлу. Виводить кореневий каталог, викликає `print_tree`, виводить підсумок.

### 2.3. Опис та реалізація функцій

#### 2.3.1. Функція write_to_file

**Призначення:** Записує рядок у файл через `fprintf`.

**Код:**
```c
void write_to_file(FILE *f, const char *data) {
    fprintf(f, "%s", data);
}
```

#### 2.3.2. Функція print_tree

**Призначення:** Рекурсивно виводить дерево каталогів. Збирає записи через `opendir`/`readdir`, сортує через `qsort`, для кожного запису формує рядок з `|-- ` або `` `-- `` залежно від позиції. Для каталогів рекурсивно викликає себе з поглибленим префіксом.

**Код:**
```c
void print_tree(const char *path, const char *prefix, FILE *out,
                int *dirs, int *files) {
    DIR *dp = opendir(path);
    if (!dp)
        return;

    char **names = NULL;
    int count = 0;
    int capacity = 16;
    names = (char **)malloc((size_t)capacity * sizeof(char *));
    if (!names) { closedir(dp); return; }

    struct dirent *entry;
    while ((entry = readdir(dp)) != NULL) {
        if (*(entry->d_name) == '.')
            continue;
        if (count == capacity) {
            capacity *= 2;
            char **tmp = (char **)realloc(names, (size_t)capacity * sizeof(char *));
            if (!tmp) { /* звільняємо і виходимо */ break; }
            names = tmp;
        }
        *(names + count) = (char *)malloc(strlen(entry->d_name) + 1);
        if (!*(names + count)) continue;
        strcpy(*(names + count), entry->d_name);
        count++;
    }
    closedir(dp);

    qsort(names, (size_t)count, sizeof(char *), cmp_str);

    for (int i = 0; i < count; i++) {
        int is_last = (i == count - 1);
        const char *branch = is_last ? "`-- " : "|-- ";

        char full_path[MAX_PATH];
        snprintf(full_path, MAX_PATH, "%s/%s", path, *(names + i));

        struct stat st;
        int is_dir = 0;
        if (stat(full_path, &st) == 0 && S_ISDIR(st.st_mode))
            is_dir = 1;

        char line[MAX_PATH + MAX_PREFIX];
        snprintf(line, sizeof(line), "%s%s%s\n", prefix, branch, *(names + i));
        write_to_file(stdout, line);
        write_to_file(out, line);

        if (is_dir) {
            (*dirs)++;
            char new_prefix[MAX_PREFIX];
            snprintf(new_prefix, MAX_PREFIX, "%s%s",
                     prefix, is_last ? "    " : "|   ");
            print_tree(full_path, new_prefix, out, dirs, files);
        } else {
            (*files)++;
        }
    }

    for (int i = 0; i < count; i++)
        free(*(names + i));
    free(names);
}
```
