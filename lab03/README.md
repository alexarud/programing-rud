Лабораторна робота №3. Розробка лінійних програм

Загальне завдання: Підрахувати суму чисел у заданому діапазоні.

**Розробити** рішення, яке:
- приймає два цілі числа;
- впорядковує межі діапазону (a ≤ b);
- обчислює суму всіх чисел від a до b включно;
- виводить результат у консоль.

Рішення реалізоване у вигляді лінійної програми без використання циклів.
