Лабораторна робота №3 — Розробка лінійних програм

Модуль 2: Основи програмування на мові C
Індивідуальне завдання №20: Підрахувати суму чисел у заданому діапазоні
Тип програми: лінійна
Мова реалізації: C

1. Завдання

Розробити лінійну програму, яка:
- приймає два цілі числа a та b;
- автоматично впорядковує значення так, щоб a ≤ b;
- обчислює суму всіх цілих чисел у діапазоні від a до b включно;
- виводить результат у консоль.

2. Структура проєкту

lab03/
├── Makefile            
├── README.md          
├── doc/
│   └── lab03.txt       
└── src/
    └── main.c          

3. Хід виконання завдання

3.1 Створення проєкту та вихідного коду

- Створено директорію lab03/ з підпапками src/ і doc/
- Файл src/main.c містить вихідний код програми
- Створено Makefile для автоматизованої збірки
- Створено README.md та doc/lab03.txt для звіту

3.2 Точка входу в програму

Точка входу знаходиться у файлі src/main.c, у функції int main().

Призначення:
Функція main() є точкою входу в програму на C. Саме з неї компілятор починає виконання програми.

Чому вона повинна бути одна:
У програмі на C може бути лише одна функція main. Якщо таких функцій буде декілька, компілятор не зможе визначити, з чого починати виконання.

3.3 Запуск програми

Компіляція:
make clean
make compile

Запуск:
make run

Приклад виконання:
Введіть число a: 5
Введіть число b: 10
Сума чисел від 5 до 10 включно: 45

3.4 Налагодження (debug) та зупинка виконання

Використано: lldb

Кроки:
1. Запустити компіляцію з параметром -g:
   make clean prep compile

2. Запустити програму через lldb:
   lldb ./dist/main.bin

3. Встановити breakpoint у функції main:
   (lldb) break main

4. Запустити виконання:
   (lldb) run

5. Змінити значення змінної "на льоту":
   (lldb) print a
   (lldb) exp a = 100
   (lldb) c

Результат:
Було змінено початкову межу діапазону під час виконання програми, що вплинуло на кінцеву суму.
