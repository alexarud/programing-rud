## 2. ОПИС ПРОГРАМИ

### 2.1. Функціональне призначення

Програма призначена для побудови та виведення трикутника Паскаля двома способами.

Основні можливості:

1. При старті за допомогою `write()` виводиться інформація про автора, номер та тему лабораторної роботи.
2. Користувач вводить кількість рядків N через `read()` — з клавіатури або через pipe.
3. Виконується валідація: N повинне бути цілим числом у діапазоні [1, 20].
4. Трикутник будується **ітеративно** — через `pascal_iterative()` з динамічним виділенням пам'яті та адресною арифметикою.
5. Той самий трикутник будується **рекурсивно** — через `pascal_recursive(i, j)` для кожного елемента.
6. Обидва результати виводяться у консоль через `write()`.
7. Динамічна пам'ять коректно звільняється через `free_pascal()`.

**Обмеження на застосування:**
- кількість рядків N обмежена значенням 20 (для запобігання переповнення `int`);
- рекурсивний метод обчислює кожен елемент незалежно, тому для великих N він значно повільніший за ітеративний.

### 2.2. Опис логічної структури

#### 2.2.1. Структура функцій

Основні функції програми (описи відповідають коментарям Doxygen):

**Бібліотека (`lib.h` / `lib.c`):**

- `int pascal_recursive(int n, int k)`  
  Рекурсивно обчислює біноміальний коефіцієнт C(n, k).  
  Базові випадки: C(n,0) = C(n,n) = 1.  
  Рекурентне співвідношення: C(n,k) = C(n−1,k−1) + C(n−1,k).

- `int **pascal_iterative(int n)`  
  Будує трикутник Паскаля ітеративно. Виділяє динамічну пам'ять для n рядків, де рядок i містить (i+1) елементів. Доступ до елементів — через розіменування покажчиків.

- `void free_pascal(int **triangle, int n)`  
  Звільняє пам'ять, виділену для трикутника Паскаля.

**Точка входу (`main.c`):**

- `static void ws(const char *s)`  
  Записує рядок у stdout через `write()`.

- `static void wi(int n, int w)`  
  Записує ціле число у stdout з вирівнюванням по правому краю на `w` символів.

- `static int ri(int *out)`  
  Зчитує одне ціле число зі stdin через `read()`. Повертає 1 при успіху, 0 при помилці.

- `static void print_pascal(int **triangle, int n)`  
  Виводить трикутник через `write()`.

- `int main(void)`  
  Точка входу. Виводить інформацію про автора, зчитує N, валідує, будує та виводить трикутник обома методами.

### 2.3. Опис та реалізація функцій

#### 2.3.1. Функція pascal_recursive

**Призначення:** Рекурсивно обчислює біноміальний коефіцієнт C(n, k).

**Код:**
```c
int pascal_recursive(int n, int k) {
    if (k == 0 || k == n)
        return 1;
    return pascal_recursive(n - 1, k - 1) + pascal_recursive(n - 1, k);
}
```

#### 2.3.2. Функція pascal_iterative

**Призначення:** Будує трикутник Паскаля ітеративно з динамічним виділенням пам'яті. Доступ до елементів — через розіменування покажчиків.

**Код:**
```c
int **pascal_iterative(int n) {
    int **triangle = malloc((unsigned long)n * sizeof(int *));
    if (!triangle)
        return NULL;
    for (int i = 0; i < n; i++) {
        *(triangle + i) = malloc((unsigned long)(i + 1) * sizeof(int));
        if (!*(triangle + i)) {
            for (int j = 0; j < i; j++)
                free(*(triangle + j));
            free(triangle);
            return NULL;
        }
        *(*(triangle + i)) = 1;
        *(*(triangle + i) + i) = 1;
        for (int j = 1; j < i; j++) {
            *(*(triangle + i) + j) =
                *(*(triangle + i - 1) + j - 1) + *(*(triangle + i - 1) + j);
        }
    }
    return triangle;
}
```

#### 2.3.3. Функція free_pascal

**Призначення:** Звільняє пам'ять трикутника — спочатку кожен рядок, потім масив вказівників.

**Код:**
```c
void free_pascal(int **triangle, int n) {
    for (int i = 0; i < n; i++)
        free(*(triangle + i));
    free(triangle);
}
```

#### 2.3.4. Функція wi

**Призначення:** Виводить ціле число з вирівнюванням по ширині `w` через `write()` — без `printf`.

**Код:**
```c
static void wi(int n, int w) {
    char tmp[16];
    int k = 0;
    if (n == 0) {
        tmp[k++] = '0';
    } else {
        int x = n;
        while (x > 0) { tmp[k++] = (char)('0' + x % 10); x /= 10; }
        for (int a = 0, b = k - 1; a < b; a++, b--) {
            char c = tmp[a]; tmp[a] = tmp[b]; tmp[b] = c;
        }
    }
    for (int p = 0; p < w - k; p++) (void)write(1, " ", 1);
    (void)write(1, tmp, (unsigned)k);
}
```

#### 2.3.5. Функція ri

**Призначення:** Зчитує ціле число зі stdin через `read()` — без `scanf`. Повертає 1 якщо успішно, 0 якщо ввели не число.

**Код:**
```c
static int ri(int *out) {
    char buf[64];
    int n = (int)read(0, buf, 63);
    if (n <= 0) return 0;
    *(buf + n) = '\0';
    int val = 0, i = 0, found = 0;
    while (i < n && (*(buf + i) == ' ' || *(buf + i) == '\n')) i++;
    while (i < n && *(buf + i) >= '0' && *(buf + i) <= '9') {
        val = val * 10 + (*(buf + i) - '0');
        found = 1;
        i++;
    }
    if (!found) return 0;
    *out = val;
    return 1;
}
```
