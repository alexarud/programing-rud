## 2. ОПИС ПРОГРАМИ

### 2.1. Функціональне призначення

Програма призначена для частотного аналізу тексту.

Основні можливості:

1. При старті виводиться інформація про автора, номер та тему роботи.
2. Текст зчитується з stdin за допомогою `fgets()`.
3. Буфер очищається від символу `\n` через розіменування покажчика.
4. Для кожної позиції у рядку визначається кількість байтів поточного символу (`char_len`).
5. Будується частотна таблиця типу `FreqEntry[]`: кожен запис містить байти символу, кількість входжень та частку.
6. Результат сортується за спаданням частоти та виводиться у форматованій таблиці.

**Обмеження:** максимальна довжина рядка — 4095 символів; обробляється лише перший рядок.

### 2.2. Опис логічної структури

#### 2.2.1. Структура функцій

**Бібліотека (`lib.h` / `lib.c`):**

- `size_t str_len(const char *s)`  
  Довжина рядка у байтах (без `'\0'`). Рядки C мають назву "Null-terminated", оскільки закінчуються байтом `'\0'`, який є ознакою кінця рядка. Реалізована через `*(s + len)`.

- `int char_len(unsigned char first_byte)`  
  Визначає кількість байтів символу за першим байтом шляхом аналізу бітового префікса: однобайтові символи (ASCII), дво-, три- та чотирибайтові послідовності.

- `size_t char_count(const char *text, size_t byte_len)`  
  Підраховує кількість символів (не байтів) у рядку.

- `size_t build_freq_table(const char *text, size_t byte_len, FreqEntry *entries, size_t *total_chars)`  
  Сканує рядок, знаходить унікальні символи, рахує входження та обчислює частоти. Доступ через `*(entries + j)`.

- `void sort_freq_entries(FreqEntry *entries, size_t n)`  
  Сортує масив за спаданням поля `freq` методом обміну.

**Точка входу (`main.c`):**

- `int main(void)` — зчитує текст через `fgets()`, будує та виводить частотну таблицю.

#### 2.2.2. Структура даних

```c
typedef struct {
    unsigned char bytes[5]; /* байти символу + '\0' */
    int byte_len;           /* кількість байтів (1–4) */
    size_t count;           /* кількість входжень */
    double freq;            /* частота [0.0, 1.0] */
} FreqEntry;
```

### 2.3. Опис та реалізація функцій

#### 2.3.1. Функція char_len

**Призначення:** Визначає кількість байтів, які займає символ, за його першим байтом. Аналіз бітового префікса дозволяє відрізнити однобайтові та багатобайтові послідовності.

**Код:**
```c
int char_len(unsigned char b) {
    if ((b & 0x80u) == 0)     return 1;
    if ((b & 0xE0u) == 0xC0u) return 2;
    if ((b & 0xF0u) == 0xE0u) return 3;
    if ((b & 0xF8u) == 0xF0u) return 4;
    return 1;
}
```

#### 2.3.2. Функція build_freq_table

**Призначення:** Будує частотну таблицю символів. Для кожної позиції визначає байти символу, шукає його серед вже знайдених або додає новий запис.

**Код:**
```c
size_t build_freq_table(const char *text, size_t byte_len,
                        FreqEntry *entries, size_t *total_chars) {
    size_t unique = 0, total = 0, i = 0;
    while (i < byte_len) {
        unsigned char c = (unsigned char)(*(text + i));
        int clen = char_len(c);
        size_t j;
        for (j = 0; j < unique; j++) {
            if ((entries + j)->byte_len == clen &&
                bytes_eq((entries + j)->bytes,
                         (const unsigned char *)(text + i), clen)) {
                (entries + j)->count++;
                break;
            }
        }
        if (j == unique) {
            FreqEntry *e = entries + unique;
            e->byte_len = clen;
            for (int k = 0; k < clen; k++)
                *(e->bytes + k) = (unsigned char)(*(text + i + (size_t)k));
            *(e->bytes + (size_t)clen) = (unsigned char)'\0';
            e->count = 1;
            e->freq  = 0.0;
            unique++;
        }
        i += (size_t)clen;
        total++;
    }
    if (total > 0)
        for (size_t j = 0; j < unique; j++)
            (entries + j)->freq = (double)(entries + j)->count / (double)total;
    if (total_chars) *total_chars = total;
    return unique;
}
```
