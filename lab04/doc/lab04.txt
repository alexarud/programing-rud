Лабораторна робота №4 — Розробка програм, що розгалужуються

Модуль 2: Основи програмування на мові C
Рудь Олександра, гр. КН-925а
Індивідуальне завдання: Визначити, чи є задане 6-значне число "щасливим квитком"
Тип програми: з розгалуженням
Мова реалізації: C

1. Завдання

Розробити програму, яка:

приймає 6-значне ціле число;

перевіряє, чи є воно "щасливим квитком" (тобто, сума перших трьох цифр дорівнює сумі останніх трьох);

виводить відповідне повідомлення у консоль:
— "Квиток щасливий", якщо умова виконується;
— "Квиток нещасливий", якщо умова не виконується.

2. Структура проєкту
lab04/
├── Makefile            
├── README.md          
├── doc/
│   └── lab04.txt       
└── src/
    └── main.c     

3. Хід виконання завдання
3.1 Створення проєкту та вихідного коду

Було створено структуру проєкту lab04/ відповідно до вимог: з підкаталогами src/, doc/, та файлами Makefile, README.md.

У каталозі src/ створено файл main.c, у якому реалізовано логіку перевірки на “щасливий квиток”.

У каталозі doc/ створено файл lab04.txt для документування виконання лабораторної роботи.

3.2 Визначення точки входу

Головна функція int main() знаходиться у файлі main.c.

Вона є обов’язковою в кожній С-програмі, оскільки визначає, з чого починається виконання.

В проєкті не допускається наявність кількох функцій main, оскільки це спричинить помилку компіляції.

3.3 Налагодження та дослідження програми

Для налагодження використовувався відлагоджувач lldb.

Програма була скомпільована з параметром -g для генерації налагоджувальної інформації.

4. Висновки

У ході виконання лабораторної роботи:

Створено програму з розгалуженням для перевірки умовної властивості 6-значного числа;

Навченося працювати з умовними операторами (if-else) у мові C;

Виконано відлагодження програми з використанням lldb, брейкпойнтів та зміни змінних "на льоту";

Програма обробляє правильні вхідні дані та виводить коректний результат відповідно до умови.
