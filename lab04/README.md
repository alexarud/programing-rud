Лабораторна робота №4 — Розробка програм, що розгалужуються


 Завдання

Розробити програму, яка:

- приймає 6-значне ціле число;
- розбиває його на окремі цифри;
- обчислює суму перших трьох та останніх трьох цифр;
- перевіряє, чи дорівнюють ці суми;
- виводить результат у консоль:
- "Квиток щасливий", якщо суми однакові;
- "Квиток нещасливий", якщо суми різні.
